Adjoe: оптимизация и A/B-тесты креативов

История A/B-тестов креативов во всех тайтлах — с 22.05.2026 по сегодня. Тесты обновляются раз в две недели: победитель определяется по результатам теста, проигравшие креативы заменяются новыми из Creative pipeline. Панель подтягивает данные из таблицы автоматически, после каждого цикла обновления.

Кликните по любому креативу — откроется карточка с полной историей по всем тестам, где он участвовал; картинку в карточке можно увеличить. Метрики: IPM, Installs, CTR, IR — данные Adjoe DSP Reporting API, ROAS d3 — из AppsFlyer (подтягивается автоматически). У идущих сейчас тестов метрик ещё нет — они появятся, когда тест закроется. Галочка «Метрики» переключает прошлые тесты между таблицами с метриками и крупными превью креативов.
